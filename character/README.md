# Character reference files

Put Valr reference material here as `.md` or `.txt` files. `character_summary.md`
or `character_summary.txt` is included in clipboard prompts only when
`character.include_summary_in_prompt` is `true` in `config.yaml`.

These files stay on this computer. The app never uploads them; only text you
choose to paste into ChatGPT leaves the application.
